## Source (a) — Ehlers, "The Ultimate Smoother", TASC V.42:04 (2024), pp. 8–15, sidebar "UltimateSmoother Function, In EasyLanguage"

```
a1 = expvalue(-1.414*3.14159 / Period);
b1 = 2*a1*Cosine(1.414*180 / Period);
c2 = b1;  c3 = -a1*a1;
c1 = (1 + c2 - c3) / 4;
If CurrentBar >= 4 Then US = (1 - c1)*Price + (2*c1 - c2)*Price[1] - (c1 + c3)*Price[2] + c2*US[1] + c3*US[2];
If CurrentBar < 4 Then US = Price;
```
(a) Transfer function stated in the article: US = 1 − HP, HP = c1(1 − 2z⁻¹ + z⁻²)/(1 − c2 z⁻¹ − c3 z⁻²) (the V.42:04
$HighPass, NOT HP-A of V.32:1 that `HighPassFilter.c` implements). Article example Period = 20. Article claim: "zero lag
in the pass band".
D1 rule 1: `1.414` -> sqrt(2), `3.14159` -> pi. Degrees -> radians. `/ 4` and the start-up rule taken literally.
(a) Start-up: EasyLanguage CurrentBar starts at 1, so the first **3** outputs equal Price; the recursion starts on the
4th call, with US[1], US[2] = Price of calls 3, 2.

## Corrected code (pre-registered lines; .c written AFTER the spec is committed)

```c
var UltimateSmootherE(vars Price, int Period)
{
    var us_k = sqrt(2.0);
    var us_a1 = exp(-us_k*PI/Period);
    var us_b1 = 2.0*us_a1*cos(us_k*PI/Period);
    var us_c2 = us_b1;
    var us_c3 = -us_a1*us_a1;
    var us_c1 = (1.0 + us_c2 - us_c3)/4.0;
    vars us_n = series(0, 2);
    us_n[0] = us_n[1] + 1;
    vars us_US = series(Price[0], 3);
    if(us_n[0] < 4) {
        us_US[0] = Price[0];
        return us_US[0];
    }
    us_US[0] = (1.0 - us_c1)*Price[0] + (2.0*us_c1 - us_c2)*Price[1]
             - (us_c1 + us_c3)*Price[2] + us_c2*us_US[1] + us_c3*us_US[2];
    return us_US[0];
}
```
